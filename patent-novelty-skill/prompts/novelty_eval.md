# 新颖性 / FTO / 创新性评价框架

本框架在"四位一体检索"完成后使用，把零散 prior-art 转成可决策的评价结论。
评价对象 = 用户方案的一个个"技术特征组合"（目的 + 手段 + 终产品）。

## 1. 先做特征映射表

| 特征编号 | 技术目的 | 技术手段 | 终产品/效果 | 候选 IPC |
|---------|---------|---------|------------|---------|
| F1 | … | … | … | … |

每条 prior-art 归到对应特征下比较，避免"目的不同却被误判为相同"。

## 2. 分类标签（必须逐条标注）

对每条检索到的现有技术，打一种标签：

- **X（毁灭性）**：完全相同技术方案（同目的 + 同手段 + 同终产品）已公开 → 新颖性丧失，独权必须避开或放弃该特征。
- **Y（部分重叠）**：目的或手段之一相同，但关键区别点不同 → 影响创造性，需在独权/从权强调区别。
- **A（技术领域相近）**：仅属相近领域、未解决相同问题 → 作"非显而易见性"论证的对比背景。
- **空（空白）**：未检索到该组合被用于该目的 → 标记为可写入 / 可主张的创新点。

**填写示例**：
> F1「光催化 ZnO/BiOCl 活化亚氯酸盐制 ClO₂」：Su 2022 用 Nd-BiVO₄（Y，手段不同）；未检索到 ZnO/BiOCl 用于此目的（空，可写入）。

## 3. 新颖性结论（per 独立权利要求）

- 若独权全部技术特征落在某条 X 类 prior-art 内 → **新颖性不足**，列该专利/论文号。
- 否则 → **具备新颖性**，说明最接近现有技术及其差异点。

## 4. 创造性（非显而易见性）结论

- 以"最接近现有技术"为起点，判断该领域人员是否显而易见能想到本方案区别点。
- 若区别点带来预料不到效果（如选择性↑、副产物↓、能耗↓），论证**创造性突出**。
- 给出"显而易见"风险等级：低 / 中 / 高，并说明依据。

## 5. FTO 规避要点

- 列出仍有效的中国 / PCT 专利（重点看授权公告号、有效状态、权利要求范围）。
- 对每个高风险专利，给一句回避设计建议（换材料 / 改工艺参数 / 改用途限定）。
- 若方案整体落入他人专利权且难回避 → 明确提示"需自由实施(FTO)声明或许可"。

## 6. 独权窄化建议（可直接落地）

给出收窄后的独立权利要求表述草稿，例如：
> "一种……的方法，其特征在于：采用 **ZnO/BiOCl 异质结** 在可见光下活化亚氯酸盐，且 **不含有机模板剂**……"

窄化原则：保留创新点、剔除与 X/Y 类重叠的宽泛表述、用参数/材料限定拉开与 prior-art 距离。

## 7. 输出清单（报告必备段）

1. 检索式与覆盖来源（含未跑全的源及原因）。
2. 已用体系清单（X/Y，附来源号）。
3. 空白体系清单（可写入）。
4. 新颖性 / 创造性结论。
5. FTO 风险与回避建议。
6. 独权窄化草稿。
7. 局限性声明（登录未完成 / 配额耗尽 / 网络失败的具体源）。

## 8. 措辞纪律

- 每条"已有人做过"必须带可核验来源，否则写"疑似 / 待核验"。
- 不写"绝对新颖""百分百可授权"等无依据绝对化结论。
- 区分"论文公开"（破坏新颖性）与"仅专利公开但未授权"（仅作先验参考）。
